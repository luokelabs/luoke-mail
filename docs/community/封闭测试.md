# 封闭测试：邮件助手这边

给 luoke-community 写测试说明和问卷用（`projects/luoke-community.md`「对 luoke-mail」第 3–5 条）。连接邮箱的引导在 [授权码引导.md](授权码引导.md)，官网素材在 [luoke-mail.md](luoke-mail.md)。整理于 2026-10-15，对应邮件助手 0.13.18；测试期间有新的已知问题，会更新这里并告诉 luoke-community。

## 怎么报"这封分错了"，又不给邮件内容

不用新功能：卡片上看得到的东西已经够我们定位，不需要原文。请测试者照下面填（GitHub 的"问题"表单可以照这个做成选项）：

| 项 | 怎么填 |
|---|---|
| 邮箱 | QQ / 163 / 126 / Gmail / 其他 |
| Mac 的内存 | 16 / 18 / 24–48 / 64 GB 以上 |
| 在哪一页 | 收件箱 / 清理（旧邮件、已归档的邮件）/ 订阅体检 / 精选 |
| 卡片上的建议 | 回复、加入日程、待跟进、归档、移到垃圾箱、移到垃圾邮件；有没有标「可疑」 |
| 卡片上的其他标签 | 类别（工作、通知、账单……）、优先级、截止日期、「按规则」或「与规则不同」，有就照抄 |
| 应该是什么 | 同上面的选项 |
| 发件人是哪一类 | 认识的人 / 同事、客户、老师 / 银行、快递、平台这类机构的通知 / 订阅推送或广告 / 陌生人 / 冒充别人的 |
| 一句话 | 不贴原文，说是什么样的邮件、为什么该是另一个，例如"信用卡本月账单，被建议移到垃圾箱，其实还没还" |

- **截止日期算错**的，写"邮件里说的是（下周三 / 月底 / 具体日期），卡片上标成了几号"，不用写别的。
- **同时请在页面上改过来**：卡片上「改为…」选对的那个。可以勾「以后……都这样处理」，同类邮件以后都会参考。改过的建议只留在测试者自己的电脑上，我们看不到；所以反馈还是要靠上面这张表。
- **起草的回复不好**的，说"太长 / 太客气 / 意思不对 / 语言不对"就够了，别贴草稿。

## 加进问卷的题

**装机当天**（邮件助手部分，2–3 题）：

1. 连接邮箱用了多久？　5 分钟以内 / 5–15 分钟 / 15 分钟以上 / 没连上
2. 卡在哪一步（可多选）？　开两步验证 / 找不到生成授权码（应用专用密码）的地方 / 手机验证 / 填进来以后连不上 / 没卡住 / 其他：___
3. 第一次同步完，"要回复"那一格里的邮件，对吗？　都对 / 大部分对 / 一半左右 / 大多不对

**每周**（邮件助手部分，挑着用）：

1. 这周「回复 / 加入日程 / 待跟进」里，有几封不该在那？　0 / 1–2 / 3–5 / 更多
2. 有没有该回的邮件被建议归档或移到垃圾箱？　有 / 没有 / 没注意。有的话请照上面的表报一下。
3. 可疑：有没有正常邮件被标了可疑？有没有诈骗、钓鱼邮件没被标出来？
4. 这周大概改了几次建议？　0 / 1–5 / 6–20 / 更多
5. 处理模式开了吗？　开了 / 没开：还不放心 / 没开：用不着 / 没找到
6. 这周你点过哪些（可多选）？　逐封处理 / 一键处理 / 清理旧邮件 / 清理已归档的邮件 / 退订 / 都没点。点之前你会一封封看吗？　会 / 扫一眼 / 不看
7. 这周撤销过吗？撤销以后邮件回到原样了吗？
8. 清理里"建议移到垃圾箱"的，有没有你想留下的？　没有 / 有几封 / 很多 / 没用清理
9. 订阅精选挑出来的，你点开看了几条？有没有明显不该挑的，或者该挑没挑的？
10. 后台自动整理开了吗？通知是：太多 / 正好 / 太少 / 没收到 / 没开
11. 同步一次的等待能接受吗？风扇、发热、耗电注意到了吗？（16 GB 的 Mac 尤其想知道）
12. 现在你愿意让它替你处理多少邮件？　还不愿意 / 只让它归档广告和通知 / 大部分，我只看要回的 / 全部
13. 这周最有用的一件事，最烦的一件事（一句话）。

## 已知问题（写进测试说明）

- **藏起来的诈骗可能漏标**：评测里，藏在正常事务里（例如日程邀请）的写给 AI 的指令，三档的模型都会漏标一封。可疑标记是帮你多看一眼，不是保证。
- **相对日期偶尔算错**："下周三""月底"这类说法，截止日期和日程的日期偶尔会差几天。加进日历前看一眼。
- **订阅精选要时间**：积压上千封订阅时，要读几个小时（16 GB 的 Mac 更久），只在你不用电脑时做。没挑完的时间段先按阅读分数排，标"尚未挑选"。同一件事在两个月里可能各出现一次。
- **关注的话题只增不减**：螺壳推测的话题，不对的要你在记忆页点「不对」，它不会自己删。
- **网易邮箱的垃圾箱 7 天就清空**（QQ 和 Gmail 是 30 天）：在网易邮箱里，移到垃圾箱的邮件过了 7 天就撤销不了。
- **QQ 邮箱撤销大批量较慢**：QQ 不告诉我们邮件移过去后的新位置，要一封封找回来，几百封要等一会儿。
- **Gmail 过滤器导入还没在真实 Gmail 上验证过**：「规则 → 导出到 Gmail」生成的文件，照 Gmail 自己导出的格式写，但没在真的 Gmail 里导入过。用 Gmail 的测试者欢迎试一下，能不能导入、导入后管不管用，都告诉我们。
- **第一次开启后台自动整理**，macOS 会问是否允许「螺壳邮件助手」发通知，选允许才收得到提醒。
- **Mac 锁屏时**钥匙串读不到授权码，这一轮安静跳过，解锁后自动继续（测试说明里已有）。
