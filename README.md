# 螺壳邮件助手

简体中文 | [English](README.en.md)

用你 Mac 上的本地模型整理整个邮箱：每封邮件都由模型看过，告诉你哪些要回复、哪些要加入日程、哪些可以归档或移到垃圾箱；你确认了它才动手，每一步都能撤销。邮件只在你的电脑上读取和分析，不经过任何云服务。

> **English summary** ([full English README](README.en.md)). Luoke Mail (螺壳邮件助手, `luoke-mail`) sorts your whole mailbox with a model running on your own Mac. Every message gets a suggestion — reply, add to calendar, follow up, archive or move to trash — with a summary, deadline and a phishing / prompt-injection flag; nothing irreversible happens until you click, and every action can be undone. It connects to Gmail, QQ Mail, NetEase 163/126 or any IMAP server with your own app password, needs no cloud service or OAuth app, and keeps all mail and memory on the device. Part of [Luoke](https://github.com/luokelabs/luoke) by Luoke Labs. Currently in closed beta; the interface is Chinese for now.

## 它是什么、在螺壳里的位置

螺壳是螺壳实验室（Luoke Labs）出品的一组本地 AI 工具，螺壳邮件助手是其中的第一个官方应用。它只管邮件这件事本身：读邮件、给建议、在你的邮箱里执行和撤销。模型推理交给螺壳（[luoke-core](https://github.com/luokelabs/luoke-core)），由它按这台 Mac 的内存选模型、在你不用电脑时安排后台任务；关于你的理解放在各应用共用的螺壳记忆（[luoke-mem](https://github.com/luokelabs/luoke-mem)）里，邮件助手只把发生了什么记下来，由记忆归纳。整体分工见顶层仓库 [luokelabs/luoke](https://github.com/luokelabs/luoke)，组件介绍见[系统文档的邮件助手页](https://luokelabs.github.io/luoke-atlas/#mail)。

## 怎么用

到 [luoke.ai](https://luoke.ai) 下载螺壳，在螺壳的「应用」里开启螺壳邮件助手，打开后按页面连接邮箱就行；模型由螺壳准备，不用自己装。连接 Gmail、QQ、网易邮箱要用邮箱自己生成的应用专用密码或授权码，手把手的步骤见 [docs/community/授权码引导.md](docs/community/授权码引导.md)。

没有连邮箱之前，可以先用内置的示例收件箱（44 封虚构邮件）把所有功能走一遍，不会碰任何邮箱。

## 它能帮你做什么

- **分拣**：最近 30 天（可调）的邮件，不论读没读过，每封给出一个建议——回复、加入日程、待跟进、归档、移到垃圾箱——外加一句话摘要、理由、截止日期（只在邮件里明确写了期限时才标）、回复要点。冒充银行、索要验证码、试图指挥 AI 的邮件会被标为「可疑」；Gmail 确认过发件域名的，会把这个结论一并交给模型。你在手机上看完就归档的邮件（最近 7 天，Gmail），如果里面有日程或要回复，也会单独列出来提醒你。
- **每封都由模型判断**：本机模型不花钱，所以不走捷径——群发邮件也逐封判断（同一家银行的对账单和促销会分开）；同来源、同建议的邮件在页面上合成一组，可以整组处理。
- **一键处理**：所有可以直接处理的邮件（归档 / 移到垃圾箱 / 移到垃圾邮件）一次处理完，执行前列出影响。
- **逐封处理**：
  - 回复：模型起草，你在页面里改，放进邮箱的草稿箱，由你自己发送；
  - 日程：Gmail 一键打开预填好的 Google 日历，其他邮箱下载日历文件；
  - 待跟进：加星标，完成后归档。
- **随时撤销**：每个操作都记在「操作记录」里，能撤销的都能撤销。
- **订阅体检**：按发件人统计最近收了多少封、你读过几封、占了多少空间；从来不看的给出退订建议——建议前由模型分析发件人最近的邮件主题，账单、登录提醒这类平时不打开但需要保留的不会建议退订；支持一键退订（RFC 8058）、打开退订网页或写退订邮件。邮件头里没有退订方式的，会去正文里找退订链接或「回复 TD 退订」这类说明。可疑发件人一律不退订。
- **无法退订的发件人**：
  - 让它以后的邮件直接进垃圾箱（规则，可撤销）；
  - Gmail：把规则导出成过滤器文件，在 Gmail 设置里导入，以后由 Gmail 自己处理，工具不开着也有效；
  - QQ 邮箱、网易邮箱：在邮箱中拉黑，由邮箱服务器替你拦截（按邮箱给出分步指引，一键复制地址）；
  - 「清理历史邮件」：把它以前的邮件（包括已经归档的）移到垃圾箱，到期由邮箱自动清空（Gmail、QQ 30 天，网易 7 天），在那之前可以撤销。归档并不省空间，这一步才真正腾出空间。
- **今日处理**（侧栏最上面）：螺壳今天对每封邮件做了什么——按你的习惯归档了、加了标签、已读留在收件箱、等你回复或加日程、可疑——每封都能一键撤销、标为未读或改建议，改了螺壳就记住。没自动处理的也列在这里，这一页就是你每天的复查。收件箱里很早以前一直没读的邮件，螺壳也会在空闲时分析一遍、标为已读，单列在这一页里，还在等你处理的会标出是否已经过期。
- **螺壳自己的邮箱**（设置 → 邮箱）：推荐给螺壳一个专门的邮箱（比如新建一个 Gmail），把订阅、通知这类邮件转过去。设为螺壳自己的邮箱以后，那里的邮件由螺壳自己归档、移到垃圾箱，每封都在「今日处理」里、能撤销；你自己的邮箱照旧由你决定。
- **规则**：更改建议时勾选「以后……的邮件都这样处理」，或者在订阅体检里点「以后都移到垃圾箱」，以后同类邮件模型会照这条规则给建议；只有某封明显需要你亲自处理（账单快到期、安全警告、有人直接问你）或可疑时，才会提出不同建议并标「与规则不同」。每个收件箱的规则各管各的，在示例邮件里试的规则不会影响你的邮箱。
- **导出到 Gmail**：规则只在你打开工具整理时生效；Gmail 用户可以把规则导出成过滤器文件（`mailFilters.xml`），在 Gmail 设置里「导入过滤器」，以后由 Gmail 自己执行。不需要 Google 授权，也没有任何服务器经手。
- **后台自动整理**：由螺壳在登录时启动、一直运行（从源码运行时只在程序开着时整理）；每隔一段时间（15 分钟到 2 小时）读一次新邮件并分拣，有要回复、要加日程、待跟进的新邮件时发一条系统通知，点通知就打开页面。分析过的邮件标为已读，按你确认过的习惯归档或加标签；每晚 20:00 提醒你在「今日处理」里看一眼。不会移到垃圾箱、退订或发信。本机模型服务没开时新邮件先存着，等它开了再分析；连不上邮箱、模型没开这类问题只提醒一次。从螺壳的「应用」或启动台打开「螺壳邮件助手」就回到页面。
- **清理**（侧栏「清理」，两栏）：
  - **收件箱里的旧邮件**：比分拣范围更早的邮件，只读邮件头（1000 多封几秒），空闲时由本机模型自动读取、逐封分析（可以暂停；分析好了收件箱顶部会写建议，全部分析完发一次通知），处理照旧要你确认：广告和一次性通知建议移到垃圾箱，可能未处理完的（未付的账单、未回复的问题）列为「待确认」，其余建议归档；未分析的默认不勾，自己勾上才会直接归档。加了星标、或贴了「收藏」「重要」这类标签的不动；分批执行、每批核实，处理中途可以停止；能撤销（进程中途退出也能撤销已经做完的），已读未读都恢复原样；没勾选的下次还是不勾。
  - **已归档的邮件**：点「开始分析」后由本机模型逐封分析（同一个发件人的邮件攒成一批问，所以同一家银行的对账单和促销会分开判断），分成「建议移到垃圾箱」（广告促销、订阅内容、验证码和物流这类一次性通知）和「建议保留」（账单收据、合同文件、行程、账号安全、个人和工作往来）；你贴过的标签也会交给模型参考、在页面上显示。建议移到垃圾箱的默认勾选（Gmail 30 天后清空垃圾箱），分批核实、能撤销，撤销时把标签贴回去；加星标的不动。分析在后台进行、结果会保存，同步和后台整理优先：1.3 万封在 M5 Max 上约一个半小时，16 GB 的机器可以挂一夜。
- **订阅精选**：本机模型替你读订阅邮件（日报、周刊、推送），一封里有多条内容就逐条看，再像编辑一样互相比较，最近一周挑出约 20 条、更早的每月约 10 条，附摘要和推荐理由；同一件事只列一次。两种来源：
  - 清理积压的订阅时，先选「先挑出值得看的…」：读完后含精选内容的邮件保留并加星标，其余照常移到垃圾箱；
  - 加入精选的发件人（在清理或订阅体检里加入），以后的新邮件汇总到每周精选，后台自动整理每周提醒一次。
  每条都可以「收藏」（一直留在「收藏」里）、「归档」（看完了，移出列表，可在「已归档」里找回）或点「没兴趣」；收藏和没兴趣之后的挑选会参考。关注的话题不用自己写：螺壳记忆根据你的网站和博客（在记忆页填写网址）、邮箱标签、你常打开的订阅、你的反馈归纳，用于挑选，不对的点「不对」。读一封十几秒（Qwen3.8 Flash-Next），积压一千多封可以放一夜，阅读和挑选只在空闲时进行。
- **记忆**：螺壳记住关于你的信息——关于你、你的网站和博客、处理习惯、关注的话题、不感兴趣的内容——用于判断邮件优先级、起草回复和挑选精选。每一条都能看到依据，能修改、删除。记忆由螺壳的工具共用（[螺壳记忆](https://github.com/luokelabs/luoke-mem)），只保存在本机。
- **从邮件中了解你**（默认开启，可以在记忆页暂停）：不用自己填写。螺壳在空闲时读你的邮件，包括你发出的：多封邮件一致的信息（职位、单位、署名、常往来的同事和客户）直接记下，转发和引用的别人的话不算；收到的往来邮件（银行、房东、学校……）按证据多少决定用不用；你常读的订阅讲什么、你怎么处理哪类邮件，螺壳记忆都从原文里学。真正需要你来定的，记忆页「想问你的」里会问你，条数显示在侧栏「记忆」旁。密码、验证码、完整的卡号和证件号不会存进记忆，只遮住那一串。
- **功耗**（设置里）：全速、均衡、安静三档，限制本机模型的运行时间，降低发热和风扇噪音；后台任务会相应变慢。
- **增量**：只下载和分析没见过的邮件，分析过的不会重复跑。

## 安全承诺

- **能撤回的先做，你事后看**：分析过的邮件标为已读；你确认过的处理习惯（比如「某某商城的促销邮件都归档」，只管这个发件人的这一类邮件，不碰它的账单和安全提醒；你在 Gmail 或手机上自己的处理也会被学到）会照着自动归档、标已读或加标签。每封都列在「今日处理」里，能一键撤销，撤销一次就记下这条习惯不一定对。
- **不可逆的你点了才动**：在你自己的邮箱里，移到垃圾箱、标垃圾邮件、退订永远不会自动做，只给建议；批量移到垃圾箱、清理历史邮件要先开启「处理模式」，再逐次确认。
- **永远不做**：不发信、不永久删除、不转发；邮件里写给 AI 的指令一律当作数据，不执行。
- **不要 Google 授权**：连接 Gmail 用的是你自己生成的应用专用密码，存在你电脑的钥匙串里；Gmail 过滤器靠你自己导入文件。螺壳没有注册任何能访问你邮箱的应用，也没有服务器。
- **示例模式**：内置一个 44 封的示例收件箱，连接邮箱之前所有功能都能先在示例里试，不会碰任何邮箱（连好邮箱后不再显示）；示例有自己的一份记忆，不会影响你的。示例邮件均为虚构，其中出现的公司名只用来模拟真实的收件箱（包括冒充银行和 Apple 的钓鱼邮件）。
- **数据不出你的设备**：模型只在你的 Mac 上运行，邮件、记忆都在本机处理，不上传。在你的设备上，螺壳会读它需要的一切，好真正懂你：记忆保存在 `~/.luoke/mem.db`，只有你的账户能读，每一条都能查看依据、修改和删除；密码、验证码、完整的卡号和证件号不存进记忆。

## 支持的邮箱

| 邮箱 | 需要准备 | 备注 |
|---|---|---|
| Gmail | 开启两步验证，生成「应用专用密码」 | IMAP 默认开启。公司的 Google Workspace 账号可能被管理员禁用 |
| QQ 邮箱 | 网页版「设置 → 账号与安全」开启 IMAP，生成 16 位授权码 | 不能用 QQ 密码 |
| 网易 163 / 126 | 网页版「设置 → POP3/SMTP/IMAP」开启 IMAP，记下授权码 | 不能用登录密码 |
| 其他 | 手动填写 IMAP 服务器和端口 | 高级选项 |

各家邮箱的差别（网易必须先发 ID 命令、QQ 遇到不认识的命令会卡住、中文文件夹名编码、Gmail 用标签归档、139 这类服务器只支持 RSA 密钥交换）都在代码里处理好了，见 [docs/DESIGN.md](docs/DESIGN.md)。

## 数据和隐私

**只在本机**：模型在你的 Mac 上运行，邮件、分析结果、记忆都在本机处理和保存，不上传。螺壳没有服务器，也没有注册任何能访问你邮箱的应用。

**什么时候联网**（2026-10 照代码逐条核过，螺壳的联网清单里邮件助手那一节）：

- **你自己的邮箱服务器（IMAP）**：同步、处理时，以及后台自动整理和空闲任务定时连接。连的是 imap.gmail.com、imap.qq.com、imap.163.com、imap.126.com 或你填的服务器。除了读，还会在你的邮箱里归档、标已读、加标签、存草稿；移到垃圾箱要你点。
- **一键退订**：你在「订阅体检」里点退订时，向发件人在邮件头里给的退订地址发一次请求（RFC 8058）。发过可疑邮件的发件人一律不退订。
- **你填的网站或博客**：在记忆页添加时读一次，之后每 30 天在后台重读。
- **你点开的链接**：在 Gmail 中打开、加入 Google 日历（网址里带日程标题、时间、地点和邮件摘要）、退订网页、精选里的文章，都交给浏览器打开。
- **模型服务**：打包版只连本机的螺壳；从源码运行时连你填的地址。

模型的输出不会让程序去连一个新地址：要连的地址都来自你的设置、邮件头或你填写的内容。

**数据放在哪**：

- 设置：`~/.luoke-mail/config.json`（可以用 `LUOKE_MAIL_HOME` 换位置）
- 邮件的分拣结果、规则、操作记录：`~/.luoke-mail/luoke.db`（SQLite）
- 授权码：macOS 钥匙串（服务名 `luoke-mail:imap`，每个邮箱各一条；直连时模型的 API Key 在 `luoke-mail:engine`）；其他系统暂存在 `~/.luoke-mail/credentials.json`（权限 600），页面会提示这是明文
- 页面的访问令牌：`~/.luoke-mail/token`（权限 600）；整个 `~/.luoke-mail` 设为只有你的账户能读（700）
- 后台日志：`~/.luoke-mail/service.log`（不写令牌）
- 记忆：螺壳记忆 `~/.luoke/mem.db`，由螺壳的应用共用；每一条都能在记忆页查看依据、修改和删除。密码、验证码、完整的卡号和证件号不存进记忆，只遮住那一串

「设置 → 数据 → 全部清除」会删掉邮件助手的以上数据，邮箱里的邮件不受影响；记忆默认保留，勾选后才删除邮件助手记下的那部分。

## 安全设计

- 页面服务只监听 `127.0.0.1`。第一次启动时生成随机令牌（保存在只有你能读的文件里，后台服务重启后已经打开的页面还能用），所有接口都要带上它，并校验 Host 头，防止你访问的其他网站偷偷调用本机接口（CSRF / DNS rebinding）。同一个数据文件夹只会有一个螺壳邮件助手在运行，再启动一次只会打开已经在运行的那个。
- 系统通知里有发件人和主题，只在你这台电脑上显示；通知文字作为数据交给系统，不会被当成脚本执行。
- 邮件正文在页面上一律按纯文本渲染，邮件里的 HTML 和脚本不会执行。
- 模型输出被约束为固定字段、固定选项的 JSON；模型只产出建议，不直接触发任何邮箱操作。
- 写操作只移动和打标记；服务器不支持 MOVE 时退回「复制 + 标记删除」，只清理自己标记的那几封，绝不清空整个文件夹。撤销按 Message-ID 找回邮件。

## 从源码运行和开发

适合开发者和想用自己的模型服务做实验的人；普通用户请用上面的螺壳。

需要：macOS（Windows / Linux 还在适配）、Python 3.9 或更新（macOS 自带的 `/usr/bin/python3` 就行，只用标准库，没有第三方依赖），以及一个 OpenAI 兼容的本地模型服务（oMLX、LM Studio、Ollama、llama.cpp 都行）。螺壳记忆要和本仓库并排放：

```bash
git clone https://github.com/luokelabs/luoke-mail.git
git clone https://github.com/luokelabs/luoke-mem.git     # 放在 luoke-mail 旁边
cd luoke-mail
python3 -m luoke_mail                                    # 默认端口 8765，自动打开浏览器；--port、--no-browser
```

浏览器会打开一个只有本机能访问的页面，按向导连接邮箱、选择本机模型（从源码运行时可以直连任何 OpenAI 兼容服务；打包的 .app 只走螺壳）。从源码运行时，后台自动整理只在程序开着时进行。数据目录可以用环境变量 `LUOKE_MAIL_HOME` 换到别处，做实验时建议这样做。

跑测试（不需要真实邮箱或模型：测试自带模拟 IMAP 服务器，有 Gmail / QQ / 网易三种风格，含写操作和撤销，还有模拟的模型服务和螺壳）：

```bash
python3 -m unittest discover -s tests
(cd ../luoke-mem && python3 -m unittest discover -s tests)
```

前端是原生 ES 模块，没有构建步骤。不碰真实数据的页面预览：`python3 tests/ui_harness.py`（假 Gmail、假模型、临时数据目录，端口 8799）。

### 用同一套题测你自己的模型

内置 48 封模拟邮件（中英文、含钓鱼和提示注入，其中 20 封是难题；2026-10-26 加了 1 封一串长跟踪链接后面写着截止日期的，2026-10-10 加了 5 封藏着注入指令的，2026-10-15 加了 2 封带邮箱服务商发件域名验证的：银行官方域名的审批结果通知、验证通过的仿冒域名，都只用于评测，不进示例收件箱），每封都在生成时定好了可接受的答案，不含任何真实数据。任何 OpenAI 兼容的本地服务都能测：

```bash
python3 bench/run_bench.py --base-url http://127.0.0.1:1234/v1 --model <模型名>
python3 bench/summarize.py        # 汇总成表格
```

分数包括：建议动作、可疑识别、误报、日期（截止日期和活动日期）、误标截止（不需要处理的邮件被标了截止日期）、优先级、一次输出合法 JSON 的比例、每封耗时。欢迎把结果分享到螺壳社区。

分拣以外，清理判断、订阅体检的发件人判断、「从邮件中了解你」也各有一套题（同样是虚构的邮件，都有不能错的硬性条目：该留的邮件不能建议移到垃圾箱，银行账单和登录提醒不能建议退订，别人的话不能当成你说的，密码和证件号不能记）：

```bash
python3 bench/run_tasks.py --base-url http://127.0.0.1:1234/v1 --model <模型名>
```

### 直连时选哪个模型

从源码运行、直连自己的模型服务时，可以参考下面的结果（打包版的模型由螺壳按内存档选，见上面「现状」）。

| 你的内存 | 推荐模型 | 全对 | 每封耗时 |

| 96 GB 以上 | Qwen3.8 Flash-Next | 45/45 | 约 3 秒（M5 Max） |
| 48 GB 以上 | gemma-4-26B-A4B（或 Qwen3.6-35B-A3B） | 44/45（Qwen3.6 旧题集 38/40） | 约 2.5 秒（约 2 秒） |

「旧题集」是 2026-10-10 加 5 封注入题之前的 40 封，这几个模型还没补测新题。

几点说明：

- 分拣是后台批量做的，慢一点问题不大：20 封邮件在 16 GB 的 M1 上，Bonsai 约 10 分钟、9B 约 5 分钟。
- 9B 的失误主要是把「问你什么时间方便」的邮件当成「加入日程」，还会漏掉藏在会议邀请里的注入指令；更小的模型漏掉的诈骗和注入邮件更多，所以不再推荐（仍可手动选用）。
- 所有操作都要你点击确认，所以模型判断错了也不会直接动你的邮箱。
- **这套题对大模型仍然测满**（Flash-Next 在 45 封上全对；旧题集上还有两个模型 40/40），只能区分大、中、小三档；而且当前提示词是在看过这些题的失分后改进的，分数可能偏乐观。新加的 5 封注入题拉开了 16 GB / 32 GB 档的差距。欢迎往 `luoke_mail/samples.py` 里补充更难、更贴近真实收件箱的题。
